# playground/ — Milestone 1 sandbox (throwaway)

Week-1 training wheels: a hand-written Qwen3-0.6B text engine. Learn the decode loop + KV
cache here once, then port the pattern to the Whisper decoder in Milestone 2. This dir may be
deleted or archived later. Full plan: `../local/Milestones/1-mini-nano-vllm.md`.

## Files
| File | Who writes it | What |
|---|---|---|
| `ref_hf.py` | ✅ done (harness) | The **answer key**: HuggingFace `generate(do_sample=False)` → dumps token ids + arch facts to `ref_qwen.json`. NOT the engine. |
| `ref_qwen.json` | generated by `ref_hf.py` | Reference token ids + config facts to check the engine against. |
| `qwen.py` | **you** (MM 1.1–1.3) | The hand-written engine: weight load → forward → greedy → KV cache → static batching. |

## Setup (run in your chosen environment — Kaggle GPU or local CPU)
```bash
pip install -r ../requirements.txt
# download weights into a gitignored local dir:
huggingface-cli download Qwen/Qwen3-0.6B --local-dir models/qwen3-0.6b
# build the answer key (also prints + saves the arch facts):
python ref_hf.py --dtype float32          # fp32 = most reproducible for the correctness gate
```

## The correctness gate (do this before trusting any tokens/sec)
Your `qwen.py` greedy output must match `ref_qwen.json`'s `generated_ids` **token-for-token**
(first ~20–30 tokens), running in the **same dtype/device** as the reference. Match = engine
correct → measure speed. Early mismatch (token 1–2) = real bug; late drift in bf16 = floating
point, not a bug.
